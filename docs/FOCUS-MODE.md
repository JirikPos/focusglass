# Nerušit a šedý iPhone během focusu

## Nerušit na Macu

1. Otevři aplikaci **Zkratky** a vytvoř dvě zkratky s akcí *Nastavit režim soustředění*:
   - **FocusGlass On** → Nerušit zapnout
   - **FocusGlass Off** → Nerušit vypnout
2. Ve FocusGlass (ozubené kolo) zapni *Nerušit během focusu*.

FocusGlass je pak spouští sám při startu a konci focusu.

## Šedý iPhone

Mac iPhone přímo ovládat nesmí, ale jde to řetězem přes režimy soustředění.

1. **Mac → Nastavení systému → Soustředění:** vytvoř režim „Deep Work“ a zapni **Sdílet mezi zařízeními**.
2. Zkratky z předchozí sekce nastav na zapnutí / vypnutí Deep Work.
3. **iPhone → Nastavení → Zpřístupnění → Displej a velikost textu → Barevné filtry:**
   filtr nastav na *Odstíny šedé* (samotný přepínač nech vypnutý).
4. **iPhone → Zkratky → Automatizace → Nová:** *Soustředění* → Deep Work → *Při zapnutí* →
   *Spustit okamžitě* → akce **Nastavit barevné filtry: Zapnout**.
   Druhá automatizace *Při vypnutí* → **Vypnout**.

Start focusu na Macu → iPhone zešedne. Konec focusu → barvy zpět.
